# Clinica Psicologa Atacalma

La clinica Atacalma es una clinica psicologa ubicada en Copiapo. Aqui, la psicologa Ingrid Miranda, psicologa con 14 años de experiencia. Ella realizara evaluaciones de habilidades, de personalidad, psicoterapia, entre otros servicios. En esta primera actividad se creo la pagina principal para este negocio.

Esta pagina sera principalmente informativa, donde se dara a conocer: La ubicacion de la clinica, la psicologa encargada, los #servicios y el precio de estos, y varias formas de contato con la clinica.

Las secciones del sitio web son: El header, el Hero, "Sobre nosotros", Informacion sobre la psicologa, Los servicios y precios, y en el footer, la informacion de contacto.
